# feature Specification

## Purpose

The `feature` module defines an Eclipse feature that packages the ASM model plugin for installation into Eclipse IDE via P2 update sites.

## Architecture

Uses Tycho `eclipse-feature` packaging. The feature includes the `hu.blackbelt.judo.meta.asm.model` plugin and its transitive dependencies required for Eclipse integration.

## Requirements

### Requirement: Eclipse feature packaging

The feature SHALL package the ASM model plugin so it can be installed into Eclipse IDE.

#### Scenario: Feature includes model plugin
- **GIVEN** the feature definition
- **WHEN** the feature is built with Tycho
- **THEN** the resulting feature includes `hu.blackbelt.judo.meta.asm.model` and all required plugins

### Requirement: P2 installability

The feature SHALL be installable via Eclipse's "Install New Software" mechanism.

#### Scenario: Install from update site
- **GIVEN** the P2 update site generated by the `site` module
- **WHEN** a user adds the site URL in Eclipse and selects the ASM feature
- **THEN** the feature installs successfully with all dependencies resolved
