# `model-test/src/test/java/hu/blackbelt/judo/meta/asm/runtime` — behaviour tests for `AsmUtils`, `AsmModel`, EMF builders and inheritance resolution

| File | Purpose |
|---|---|
| `AnnotationTest.java` | Covers `ExtendedMetadata` annotation API of `AsmUtils` on the shared demo model. Exercises `getExtensionAnnotationByName(e, name, createIfNotExists)`, `getExtensionAnnotationListByName`, `addExtensionAnnotation`, `addExtensionAnnotationDetails`, `getExtensionAnnotationValue`, `getExtensionAnnotationCustomValue`, `getResolvedExposedBy`, `getActorTypesOfOperation`, `getMappedEntity` / `getMappedAttribute` / `getMappedReference`, `annotatedAsFalse` / `annotatedAsTrue`. Pins contract that create-flag `true` yields annotation with `EXTENDED_METADATA_DETAILS_VALUE_KEY` not set to `true`. Extends `ExecutionContextOnAsmTest` — depends on its demo `Order` / actor fixtures. |
| `AsmUtilsTest.java` | Covers naming, lookup and derivation API of `AsmUtils` on the demo model. Asserts FQN builders `getPackageFQName` → `demo.services`, `getClassifierFQName` → `demo.types.Countries`, `getAttributeFQName` → `demo.services.__Static#totalNumberOfOrders`, plus `getOperationFQName`, `resolve`, `getClassByFQName`. Bulk of file exercises mapped-transfer-object-type derivation for non-entity, already-present, inheritance, reference-typed and cyclic model shapes. `testValidateUniqueXmiids` pins that `validateUniqueXmiids()` passes on distinct `setId` values and throws `IllegalStateException` on a duplicate xmiid. `targetDir()` resolves the code-source dir and mkdirs it for `.ecore` output. Named in module build docs as `-Dtest=AsmUtilsTest`. |
| `AsmValidationTest.java` | Concrete parity case on `AbstractAsmValidationTest`; `@ParameterizedTest` + `@EnumSource(ValidatorType.class)` runs `testEmptyModelPassesValidation` under both `EVL` and `JAVA`. Asserts empty model yields no errors and no warnings. Placeholder-shaped: `asm.evl` currently declares no rules, so this is the parity floor, not coverage. |
| `EmfBuilderTest.java` | Verifies `AsmModel` builder + save/validate contract using `EcoreBuilders` company metamodel. `buildValidCompanyMetamodel` builds via `AsmModel.buildAsmModel().uri(...)`, `addContent`, `saveAsmModel()`, asserts `isValid()`. `buildInvalidCompanyMetamodel` adds an `EPackage` with `nsPrefix` but no name and pins the exact diagnostic `The name 'null' is not well formed`, that `saveAsmModel()` then throws `AsmModel.AsmValidationException`, and that `SaveArguments.asmSaveArgumentsBuilder().validateModel(false)` bypasses the check. Standalone — does not extend the shared fixture. |
| `ExecutionContextOnAsmTest.java` | Package-private fixture superclass, not a test itself. Exposes fields `asmModel`, `asmUtils` and `setUp()`, which builds model at `urn:asm.judo-meta-asm`, calls `populateAsmModel()` to construct the demo `Countries` enum, `Timestamp`/`String`/`Double`/`Integer`/`Binary` datatypes plus entity, service and actor packages, asserts `isValid()`, then runs `AsmEpsilonValidator.validateAsm` against `calculateAsmValidationScriptURI()` with empty expected lists. Subclass `@BeforeEach` must delegate to `super.setUp()` or `asmUtils` stays null. EVL failure rethrows `EvlScriptExecutionException` after logging unexpected errors/warnings. |
| `InheritanceTest.java` | Pins EMF inheritance semantics `AsmUtils` derives on. `testInheritedAttributes` builds `Person` → `Employee` and fails on any `Resource.Diagnostic` error after serialization. `testOperationInMultipleInheritance` builds a diamond/multi-supertype `EClass` graph and drives helper `assertOperations(clazz, expectedAllOperationNames, expectedAllOperationDeclarations, expectedAllOperationImplementations, expectedAllAbstractOperationNames)`, which cross-checks static `AsmUtils.getAllOperationNames`, `getAllOperationDeclarations(clazz, ignoreOverrides)`, `getAllOperationImplementations` and `getAllAbstractOperationNames`. Contract asserted: declarations with and without overrides must be equal. Uses `AsmModelResourceSupport` and writes `.ecore` under `targetDir()`. |
