# `osgi-itest/src/test/resources/etc` — Karaf `etc/` overrides copied into the Pax Exam container by `KarafFeatureProvider`

| File | Purpose |
|---|---|
| `org.ops4j.pax.logging.cfg` | pax-logging log4j2 config, unconditionally swapped into container `etc/` via `replaceConfigurationFile`. Sets `log4j2.rootLogger.level = DEBUG` with appenders `Console`, `RollingFile` (`${karaf.log}/karaf.log`, `SizeBasedTriggeringPolicy` 16MB) and `PaxOsgi` (filter `*`); console output is gated separately by a `ThresholdFilter` on `${karaf.log.console:-INFO}`, so raising console verbosity needs the `karaf.log.console` property, not the root level. Pattern `log4j2.pattern` includes `bundle.id`/`bundle.name`/`bundle.version` MDC keys. Aether / pax-url `TRACE` loggers are present but commented out. File ends with a stray line containing a single `s`. |
| `org.ops4j.pax.url.mvn.cfg` | pax-url-aether resolver config, applied ONLY when system property `useCustomSettings` is true (`when(Boolean.getBoolean("useCustomSettings"))` in `karafConfig`). Points `org.ops4j.pax.url.mvn.settings` at `${basedir}/../.maven.xml`, sets `certificateCheck=true`, `useFallbackRepositories=false`, and defines `defaultRepositories` (karaf system/kar/child repos, all `@snapshots`) plus remote `repositories` central, Apache snapshots, ops4j sonatype snapshots. Central is listed over plain `http://repo1.maven.org/maven2`, which modern Maven Central rejects — treat as legacy. Timeouts: `timeout`/`connectionTimeout` 5000 ms, `readTimeout` 30000 ms, `retryCount` 3. |
