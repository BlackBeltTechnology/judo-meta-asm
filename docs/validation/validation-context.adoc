== Overview

The `ValidationContext` interface provides access to the model and validation state during rule execution. It is passed to every validation rule as the second parameter.

== Interface Definition

[source,java]
----
public interface ValidationContext {

    /**
     * Get all instances of a specific type in the model.
     *
     * @param type The EClass type to search for
     * @return List of all instances of the specified type
     */
    <T extends EObject> List<T> getAllInstances(Class<T> type);

    /**
     * Check if a constraint has passed for a specific element.
     *
     * @param element The element to check
     * @param constraintName The name of the constraint
     * @return true if the constraint passed, false otherwise
     */
    boolean satisfies(EObject element, String constraintName);

    /**
     * Call an extension method on an element.
     *
     * @param target The target element
     * @param methodName The extension method name
     * @param args Additional arguments
     * @return The method result
     */
    <T> T call(EObject target, String methodName, Object... args);

    /**
     * Get a cached value.
     *
     * @param key The cache key
     * @return The cached value, or null if not present
     */
    Object getCached(CacheKey key);

    /**
     * Store a value in the cache.
     *
     * @param key The cache key
     * @param value The value to cache
     */
    void putCached(CacheKey key, Object value);

    /**
     * Clear all cached values.
     */
    void clearCaches();

    /**
     * Get the validation registry.
     *
     * @return The validation registry
     */
    ValidationRegistry getValidationRegistry();

    /**
     * Get the extension method registry.
     *
     * @return The extension method registry
     */
    ExtensionMethodRegistry getExtensionMethodRegistry();

    /**
     * Get the resource set containing the model.
     *
     * @return The EMF resource set
     */
    ResourceSet getResourceSet();
}
----

== Common Usage Patterns

=== Getting All Instances of a Type

[source,java]
----
@Constraint(name = "NameMustBeUnique", message = "Name must be unique")
public ValidationRule nameMustBeUnique() {
    return (element, ctx) -> {
        EntityType entity = (EntityType) element;

        // Get all EntityType instances in the model
        List<EntityType> allEntities = ctx.getAllInstances(EntityType.class);

        // Check for duplicates
        long count = allEntities.stream()
            .filter(e -> entity.getName().equals(e.getName()))
            .count();

        return count == 1
            ? ValidationResult.pass()
            : ValidationResult.fail("Duplicate name: " + entity.getName());
    };
}
----

=== Checking Constraint Dependencies

[source,java]
----
@Constraint(name = "ValidateName", message = "...")
public ValidationRule validateName() {
    return (element, ctx) -> {
        // Check if another constraint passed
        if (!ctx.satisfies(element, "EntityMustExist")) {
            // Skip validation if dependency not satisfied
            return ValidationResult.pass();
        }

        // Proceed with validation
        // ...
    };
}
----

=== Calling Extension Methods

[source,java]
----
@Constraint(name = "ValidateSuperTypes", message = "...")
public ValidationRule validateSuperTypes() {
    return (element, ctx) -> {
        EntityType entity = (EntityType) element;

        // Call extension method
        Collection<EntityType> superTypes = ctx.call(
            entity,
            "getAllSuperTypes"
        );

        // Use the result
        if (superTypes.contains(entity)) {
            return ValidationResult.fail("Circular inheritance detected");
        }

        return ValidationResult.pass();
    };
}
----

=== Caching Expensive Computations

[source,java]
----
@Constraint(name = "ValidateComplexRule", message = "...")
public ValidationRule validateComplexRule() {
    return (element, ctx) -> {
        EntityType entity = (EntityType) element;

        // Create cache key
        CacheKey key = CacheKey.builder()
            .element(entity)
            .methodName("computeExpensiveResult")
            .build();

        // Check cache first
        Object cached = ctx.getCached(key);
        if (cached != null) {
            return processResult((ExpensiveResult) cached);
        }

        // Compute and cache
        ExpensiveResult result = computeExpensiveResult(entity);
        ctx.putCached(key, result);

        return processResult(result);
    };
}
----

== AsmUtils Integration

The `ValidationContext` in ASM provides access to `AsmUtils` for model traversal:

[source,java]
----
public class ValidationContext {
    private final AsmUtils asmUtils;

    public ValidationContext(AsmUtils asmUtils, ResourceSet resourceSet,
                            ExtensionMethodRegistry extensionRegistry) {
        this.asmUtils = asmUtils;
        // ...
    }

    public AsmUtils getAsmUtils() {
        return asmUtils;
    }
}
----

=== Using AsmUtils in Validation Rules

[source,java]
----
@Constraint(name = "ValidateModel", message = "...")
public ValidationRule validateModel() {
    return (element, ctx) -> {
        AsmUtils asmUtils = ctx.getAsmUtils();

        // Use AsmUtils methods
        List<EClass> allClasses = asmUtils.all(EClass.class)
            .collect(Collectors.toList());

        // Validate...
    };
}
----

== Thread Safety

The `ValidationContext` is designed for use in parallel validation:

* `getAllInstances()` returns a thread-safe snapshot
* `getCached()` and `putCached()` use concurrent data structures
* Extension method calls are thread-safe when methods are stateless
