# `model/src/main/java/hu/blackbelt/judo/meta/asm/runtime` — runtime API of the ASM model: load/save wrapper, Ecore query helpers, per-`ResourceSet` cache, EVL driver

| File | Purpose |
|---|---|
| `AsmEpsilonValidator.java` | Drives EVL validation of an `AsmModel` through the epsilon runtime. Exports three static `validateAsm` overloads — `(Logger, AsmModel, URI scriptRoot)`, `+ (expectedErrors, expectedWarnings)`, `+ (useCache)` — plus `calculateAsmValidationScriptURI()`. Builds an `ExecutionContext` binding model name `ASM` with `validateModel(false)`, injects context variable `asmUtils` as a fresh `AsmUtils(asmModel.getResourceSet())`, resolves `asm.evl` under `scriptRoot`, runs with `parallel(true)`. Unexpected results raise `ScriptExecutionException`; context is always committed and closed in `finally` (close errors swallowed). `calculateAsmValidationScriptURI()` derives `validations/` from the code-source location of `AsmModel` and special-cases `.jar` and `jar:bundle:` layouts — relocating the class or the `validations/` folder breaks resolution. |
| `AsmModel.java` | Facade over an ASM Ecore resource; the module's main public entry point. Exports builder `buildAsmModel()` (`uri`, `resourceSet`, `uriHandler`, `asmModelResourceSupport`), static `loadAsmModel(LoadArguments\|LoadArgumentsBuilder)`, instance `loadResource(...)`, `saveAsmModel()` / `saveAsmModel(SaveArguments\|SaveArgumentsBuilder)`, `addContent(EObject)`, `getResource()`, `getResourceSet()`, `getAsmModelResourceSupport()`, `getUri()`, `getName()`, `getVersion()`, `getDiagnostics()`, `isValid()`, `asString()`, `getDiagnosticsAsString()`, `toDictionary()`, plus nested `LoadArguments`, `SaveArguments`, `AsmModelBuilder`, and checked `AsmValidationException`. Property keys `NAME`, `VERSION`, `URI`, `RESOURCESET` are the `toDictionary()` / OSGi service-property names. Contracts: `getName()` throws `IllegalStateException` when no model `EPackage` exists; `getVersion()` defaults to `1.0.0`; load and save throw `AsmValidationException` when `validateModel` is on and diagnostics carry an ERROR — pass `validateModel(false)` to persist a knowingly invalid model. |
| `AsmUtils.java` | Query/derivation helper layer over the Ecore ASM model; the class the EVL scripts get injected as `asmUtils`. Constructed with a `ResourceSet`, shares an `AsmUtilsCache` keyed on that set. Naming: `getPackageFQName`, `getSafePackageFQName`, `getClassifierFQName`, `getAttributeFQName`, `getReferenceFQName`, `getOperationFQName`, `getRelativeFQName`, `safeName`, `getterName`/`setterName`, separators `NAMESPACE_SEPARATOR` = `.`, `FEATURE_SEPARATOR` = `OPERATION_SEPARATOR` = `#`. Lookup: `resolve`, `resolveReference`, `resolveAttribute`, `resolveOperation`, `getClassByFQName`, `all(Class)`, `getModel()`, `getId`/`setId`, `validateUniqueXmiids()` (throws `IllegalStateException` on duplicate xmiid). Annotations: `EXTENDED_METADATA_URI` = `http://blackbelt.hu/judo/meta/ExtendedMetadata`, detail key `EXTENDED_METADATA_DETAILS_VALUE_KEY` = `value`, `getAnnotationUri`, `getExtensionAnnotationByName(..., createIfNotExists)`, `getExtensionAnnotationListByName`, `addExtensionAnnotation`, `addExtensionAnnotationDetails`, `getExtensionAnnotationValue`, `getExtensionAnnotationCustomValue`, `annotatedAsTrue`/`annotatedAsFalse`, `getAnnotatedClass`/`Attribute`/`Reference`/`Operation`/`Parameter`. Classification: `isEntityType`, `isMappedTransferObjectType`, `isActorType`, `isStaticQuery`, `isStateless`/`isStateful`, `isBound`/`isUnbound`, `isEmbedded` and `isAllowedTo{Create,Update,Delete}EmbeddedObject`, datatype predicates `isInteger`/`isDecimal`/`isNumeric`/`isBoolean`/`isString`/`isText`/`isByteArray`/`isDate`/`isTimestamp`/`isTime`/`isEnumeration`/`isIdentifier` (matched on `instanceClassName` against fixed Java type lists, so a custom instance class is not recognized). Mapping and exposure: `getMappedEntityType`, `getMappedAttribute`, `getMappedReference`, `getResolvedExposedBy`, `getActorTypesOfOperation`, `getAllActorTypes`, `getDefaultRepresentation`, `isDefaultTransferObject`, `getInstanceRepresentation`, `isInstanceOperation`, `getBindOperation`. Operation resolution across inheritance: `getAllOperationNames`, `getOperationDeclarationsByName`, `getAllOperationDeclarations(clazz, ignoreOverrides)`, `getOperationImplementationListByName`, `getOperationImplementationByName`, `getAllOperationImplementations`, `getAllAbstractOperationNames`, `getImplementationClassOfOperation`, `isAbstract`, `getOutputParameterName`. Mutators `enrichWithAnnotations()` and `createMappedTransferObjectTypeByEntityType(EClass)` modify the model in place — cached derivations may go stale, and rerunning is not idempotent-free. Nested enum `OperationBehaviour` names the generated behaviours (`LIST`, `CREATE_INSTANCE`, `VALIDATE_CREATE`, `REFRESH`, `UPDATE_INSTANCE`, `VALIDATE_UPDATE`, `DELETE_INSTANCE`, `SET_REFERENCE`, `UNSET_REFERENCE`, `ADD_REFERENCE`, `REMOVE_REFERENCE`, `GET_REFERENCE_RANGE`, `GET_INPUT_RANGE`, `GET_TEMPLATE`, `GET_PRINCIPAL`, `GET_METADATA`, `GET_UPLOAD_TOKEN`, `EXPORT`, `VALIDATE_OPERATION_INPUT`) with `resolve(String type)` / `getType()` mapping to the annotation string — the string, not the constant name, is the model contract. |
| `AsmUtilsCache.java` | Per-`ResourceSet` memo store backing `AsmUtils`. Exports static `getCache(ResourceSet)`, `clear()`, `getModel()`/`setModel(Optional<EPackage>)`, and mutable-map accessors `getClassifiersByFqName`, `getReferencesByFqName`, `getAttributesByFqName`, `getOperationsByFqName`, `getPackageFqName`, `getElementsByType`, `getEntityByMappedTransfer`, `getEntityAttributeByMappedAttribute`, `getEntityReferenceByMappedReference`, `getDefaultRepresentation`, `getBindOperation`, `getInstanceRepresentation`, `getAnnotationsByModelElementAndName`, plus value type `Pair<T1,T2>` (with `builder()`, `equals`/`hashCode`) used as the annotation lookup key. Backed by a Guava `LoadingCache<ResourceSet, AsmUtilsCache>` with `expireAfterAccess` read from system property `AsmUtilsCacheExpiration` (seconds, default `60`) — instances are shared across every `AsmUtils` built on the same `ResourceSet`, and entries survive model mutation, so callers mutating the model must call `clear()`. Accessors hand out the live `ConcurrentHashMap`s; `clear()` deliberately does NOT reset `model`. |
