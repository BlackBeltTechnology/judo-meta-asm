# `model/src/main/java/hu/blackbelt/judo/meta/asm/support` — EMF `ResourceSet` plumbing under `AsmModel` (factories, load/save options, diagnostics, typed streams)

| File | Purpose |
|---|---|
| `AsmModelResourceSupport.java` | Owns the EMF `ResourceSet`/`Resource` layer `AsmModel` delegates to. Exports builder `asmModelResourceSupportBuilder()` (`resourceSet`, `uriHandler`, `uri`), `loadAsm(...)` / `loadResource(...)`, `saveAsm()` and `saveAsm(SaveArguments\|SaveArgumentsBuilder)`, `addContent(EObject)`, `getResourceSet()`, `getResource()`, `getDiagnostics()`, `isValid()`, `asString()`, `getDiagnosticsAsString()`, nested `LoadArguments` / `SaveArguments` / `AsmValidationException`. Statics: `createAsmResourceSet()`, `registerAsmMetamodel(ResourceSet)` (registers `EcorePackage.eINSTANCE` nsURI only — ASM is plain Ecore, no generated metamodel), `getAsmFactory()` (an `EcoreResourceFactoryImpl` producing an `XMIResourceImpl` with `useUUIDs()` forced `true`, so every element gets an xmiid), `getAsmModelDefaultLoadOptions()` (`OPTION_DEFER_IDREF_RESOLUTION`, `OPTION_LAX_FEATURE_PROCESSING`, dangling href `DISCARD` — unknown features and dangling refs are silently tolerated on load), `getAsmModelDefaultSaveOptions()` (`OPTION_DECLARE_XML`, `OPTION_SCHEMA_LOCATION`, `OPTION_ENCODING` `UTF-8`, plus a custom `URIHandlerImpl.deresolve` collapsing same-opaque-part URIs to bare `#fragment`), `setupRelativeUriRoot(ResourceSet, URI)` / instance `setupRelativeUriRoot()`, `setPrimaryUriHandler(ResourceSet, URIHandler)`. Element access is a typed-stream family: generic `all()`, `getStreamOf(Class)`, `asStream(Iterator, boolean parallel)`, plus one `getStreamOfEcoreE*` accessor per Ecore type (`EClass`, `EAttribute`, `EReference`, `EOperation`, `EPackage`, `EAnnotation`, `EEnum`, `EEnumLiteral`, `EParameter`, `EDataType`, `EGenericType`, `ETypeParameter`, …). Validation runs through a shared `Diagnostician`; `getDiagnostics()` returns only WARN and ERROR entries, `isValid()` is false only on ERROR, and `saveAsm` throws `AsmValidationException` unless `validateModel(false)`. |
